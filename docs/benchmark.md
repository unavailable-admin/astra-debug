```bash
python -m astrabot benchmark --output outputs/speed-test
```

每次先将空闲 Scene11 切到 arm26 再恢复 full36 以冷重置；顺序按固定种子打乱。
默认8081，可用 `--uri` 改端口。最多4次抓放，API最多重试10次。
批量任务保存代码和标定摘要；恢复运行时要求内容与地址相同。
使用新输出目录，旧版本记录不能在重构后续跑。
