# 双目定位与抓放约定

配置文件：`astrabot/config/g1_head_camera_calibrations.yaml`。
当前运行入口只支持 Scene11 的 640×480 同步双目图像。

## 仿真与真机

仿真使用 `isaac_render_offset` 对应的 OpenGL 相机到 head_link 外参，
转换为 OpenCV 光学坐标系后结合当前关节反馈的头部 FK。
使用理想针孔内参：左 fx≈fy=274.674，右 fx≈fy=276.060，主点 (320,240)，畸变为零。
连接时核对服务端分辨率、焦距与渲染外参，不一致就停止。

真机原始 K、dist、stereo R/T 单独保留为 `real` 几何配置，需去畸变和双目校正。
真机相机到头部的手眼外参未验证，因此当前控制器不是可直接部署的真机程序。
不能将原始真机畸变或主点套在 Isaac 图像上。

## 当前闭环

1. 获取当前左右图像和关节反馈，给青色字形连通域编号。
2. API 根据当前场景及字形放大图返回字母身份、候选编号和是否朝上。
3. SGBM 双目匹配与左右一致性检查重建字形表面；结合 FK 转到机器人世界坐标。
4. 已知方块边长 40mm，据此估计中心和桌面；抓取接触点为表面下 5mm。
5. 在机械臂运动前做连续 IK 路径预检，执行抓取、搬运、松手和撤回。
6. 放下后重新拍摄并调用 API；每个字母及纠正动作都重新观测。

抓起后不额外调用 API 检查是否夹住，沿用此前确认的执行方式。
只要当前身份有效、三个字母朝上、XY目标偏差均≤18mm、距手部连杆均≥100mm，才算完成。
最多两次重新观测用于缺失或低质量定位，抓放次数由 `--max-skills` 限制。

不读取对象真实位姿、场景 authored 坐标、初始参考图或旧单目标定。
仍依赖任务先验：40mm方块、平桌面、青色字形、固定目标排和当前左手工作空间。
目标排间距 9cm，默认起点 X=-0.26m、Y=1.66m；支持最多4个不重复的大写字母。

## 倍速和记录

只保留 trajectory 执行方式。`--speed` 同时压缩插值和保持帧数，范围 0.25～3。
仿真 dt 不变，视频为原始30fps；计时包括准备、动作和纠正，不含 API等待、重置和编码。
每次在 `outputs/` 中写入报告、左右帧、轨迹记录和拼接视频，该目录不进 Git。
